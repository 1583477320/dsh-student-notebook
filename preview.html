帮我把「特征值与特征向量」整理成一页复习笔记：定义、手算步骤，再给我一个 20 行以内的 Python 例子。最好有一张判别表。

一、先记住这个直觉

矩阵 A 作用在向量 v 上，通常会把方向掰弯；但如果某个方向只被拉伸、不被旋转，这个方向就是特征向量，拉伸的倍数就是特征值。 换句话说：特征向量负责“方向”，特征值负责“倍数”。

手算口诀：先解特征方程，再代回求零空间。

二、手算三步

  1. 写出 det(A − λI) = 0，解出所有特征值。
  2. 把每个 λ 代回 (A − λI)v = 0，求基础解系。
  3. 检查代数重数与几何重数是否相等，判断能否对角化。
python
import numpy as np

def power_iteration(A, steps=20):
    v = np.ones(A.shape[0])
    for _ in range(steps):
        v = A @ v
        v = v / np.linalg.norm(v)
    return v, float(v @ A @ v)

A = np.array([[4.0, 1.0], [2.0, 3.0]])
vector, value = power_iteration(A)
print(round(value, 4), np.round(vector, 3))

三、可对角化判别

矩阵 特征值 代数重数 几何重数 可对角化
diag(2, 3) 2, 3 1 + 1 1 + 1 是
[[2, 1], [0, 2]] 2 2 1 否
[[2, 0], [0, 2]] 2 2 2 是

最后检查一遍：几何重数 = 每个特征值对应的线性无关特征向量个数。它永远小于等于代数重数；一旦小于，矩阵就缺特征向量，不能对角化。
